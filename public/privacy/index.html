2. Personal information we may process

  • User-provided content: prompts, conversations, instructions, uploaded files, project material, feedback and content you choose to store in Memory Vault or another workspace.
  • Generated and workspace data: AI responses, task inputs and outputs, project records, preferences, saved settings and workflow history.
  • Operational and device data: IP address, browser or device characteristics, timestamps, diagnostic events, security logs, error reports and usage telemetry, where collected by the deployed service.
  • Integration data: limited account identifiers, permissions, repository metadata, model requests, delivery status or other information returned by a third-party service you explicitly connect and use.
  • Communications data: message content, recipient details and provider status only where you use and authorise a supported communications feature. Do not assume a communication channel is active merely because it appears in the interface.

Please avoid submitting sensitive personal information, special personal information, children’s information, passwords, API keys or other secrets unless a specific feature expressly supports the information and the processing is lawful and necessary.
